Import the cutting candidates, not the reference artwork

  • GRAIN_REFERENCE and LABELS: grain arrow, IDs, dimensions and warnings; do not machine.

The eventual operation plan

The certified operator determines the actual sequence and cutting values after release inputs are resolved. This sequence describes review requirements, not executable machine instructions.

  1. Release the geometry and setup sheet. Reconcile measured material with the required Rockler interior opening and every custom joint. Identify each part’s inside/outside face, front edge, grain, reference surfaces and dimensions. Keep hand/jig drilling operations on the same documented plan.
  2. Prepare inside features while the stock remains secured. Plan approved pockets, dados/rabbets and face drilling before outer-contour release where practical. Check blind-hole depth against measured stock and cutter geometry; do not infer holes from reference labels.
  3. Plan every reorientation. Distinguish first-face, second-face and edge-boring operations. Document registration, repeated zero checks and safe support. A jig follow-up for Rockler dowels or edge screw holes is valid; “CNC cut” need not mean every feature is made in one flat-sheet setup.
  4. Contour with an approved retention strategy. Check tool and collet clearances, clamp keep-outs, cutter compensation and access around each part. The operator chooses tabs or another shop-approved method and specifies when clamps/retention change. Do not release a part that a later operation still depends on holding.
  5. Finish, label and inspect the cut parts. Follow the documented release/cleanup method, preserve part IDs, inspect dimensions and fit with a sample joint before full assembly. Confirm M07 is finished to ⅝ in and retain its required 3 × 56 in size.

Proof required before cutting the project

  1. Simulate the complete CAM setup. Review tools, stock removal, blind depths, full travel, collision risks, tabs/retention and second-side alignment. Reference layers must not become machining operations.
  2. Review the posted output. The operator checks that units, work offsets, tool changes and safety behavior match the approved post and active machine profile. Simulation is not proof that an arbitrary post is compatible.
  3. Perform the shop’s dry-run/air-pass procedure. A certified operator verifies actual machine travel, workholding clearances and zero/reference setup without cutting, using HackRVA’s operating procedures rather than an improvised coordinate change.
  4. Cut a representative test coupon. Use the actual stock and selected tools to verify critical joint fit, blind-hole depth, pin/hardware fit and edge quality. Correct the geometry or setup before committing the full sheets.
  5. Inspect the first production parts before continuing. Check scale, face/orientation, thickness-sensitive fit and safe retention. If a discrepancy appears, stop and resolve it before repeating the operation across the remaining sheets.
